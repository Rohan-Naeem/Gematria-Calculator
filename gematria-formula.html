THE BASIC IDEA

How a Gematria Calculation Works

A basic gematria calculation assigns a numerical value to each letter according to a particular system. The values of the letters are then added together to produce a total.

Because different systems use different letter values, the same word can produce different numerical results depending on the selected method.

GENERAL FORMULA
Total Value = Letter 1 + Letter 2 + Letter 3 + ... + Letter N

Each letter contributes its assigned numerical value to the final total.
