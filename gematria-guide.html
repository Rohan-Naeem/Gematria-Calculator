THE BASICS

What Is Gematria?

Gematria is a system in which letters are assigned numerical values. A word, name, phrase, or sentence can then be represented by a numerical value based on the values assigned to its individual letters.

The exact method used to assign values depends on the particular gematria system. Some systems use the normal alphabetical order, while others reverse the alphabet or reduce values to single digits.

Because different systems follow different rules, the same word can produce different numerical results.

THE PROCESS

COMMON SYSTEMS

Common English Gematria Methods

GematriaCalc supports several commonly used approaches for assigning numerical values to English letters.

01 A = 1

English Ordinal

Each letter receives a value based on its position in the English alphabet. A is 1, B is 2, and Z is 26.

A = 1   B = 2   C = 3
02 1–9

English Reduced

Alphabet positions are reduced to single digits from 1 through 9.

A = 1   B = 2   I = 9
03 REVERSE

English Reverse Ordinal

Values are assigned in reverse alphabetical order. Z receives 1 and A receives 26.

Z = 1   Y = 2   A = 26
04 REVERSE + REDUCE

English Reverse Reduced

Reverse alphabet values are reduced to single-digit values before being combined.

A = 26 → 8

IMPORTANT TO KNOW

Understanding the Limitations

A gematria calculator produces a numerical result according to the rules of the selected calculation system. The number itself does not automatically establish a particular interpretation or meaning.

Different gematria systems can produce different results for the same text. Therefore, it is important to identify which method was used when comparing numerical values.

GematriaCalc is designed as an informational and educational calculation tool. Results should not be treated as predictions, guarantees, or definitive conclusions about people, events, or circumstances.
